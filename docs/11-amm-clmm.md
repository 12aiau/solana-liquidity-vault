# Задание 11. AMM и концентрированная ликвидность (Raydium CLMM)

## Классический AMM (constant product)

Пул хранит два резерва `x` (токен A) и `y` (токен B) и поддерживает инвариант
`x · y = k`. Цена `P = y / x`. Обмен `Δx` даёт `Δy = y − k / (x + Δx)` за вычетом
комиссии. Ликвидность распределена по всей кривой цен от 0 до ∞, поэтому
большая часть капитала LP почти никогда не используется.

## Концентрированная ликвидность (CLMM, Uniswap v3 / Raydium CLMM)

LP выбирает **ценовой диапазон** `[P_lower, P_upper]` и даёт ликвидность только
в нём. Внутри диапазона позиция ведёт себя как constant-product пул с
«виртуальными» резервами, поэтому тот же капитал даёт глубину в разы больше.

* **Тики.** Цена дискретизирована: `P(i) = 1.0001^i`. Граница позиции должна
  быть кратна `tick_spacing` пула (у нас 60 при комиссии 0.25%).
* **sqrtPriceX64.** Пул хранит `√P` в формате Q64.64; текущий тик `tick_current`.
* **Ликвидность L.** Для позиции в диапазоне:
  `amount0 = L · (√P_upper − √P) / (√P · √P_upper)`,
  `amount1 = L · (√P − √P_lower)`.
  * Цена ниже диапазона: позиция целиком в токене 0.
  * Цена выше диапазона: позиция целиком в токене 1.
  * Внутри диапазона: оба токена, и позиция зарабатывает комиссии.
* **Tick arrays.** Состояние тиков хранится в аккаунтах по 60 тиков
  (`start = floor(tick / (spacing·60)) · spacing·60`). Swap и позиции передают
  нужные tick array как remaining accounts.
* **Позиция = NFT.** Raydium минтит NFT позиции; `personal_position`
  (PDA `["position", nft_mint]`) хранит диапазон, `L` и накопленные комиссии.
* **Комиссии** копятся через `fee_growth_global` / `fee_growth_inside` и
  забираются через `decrease_liquidity_v2` (с `liquidity = 0` это просто сбор
  комиссий).
* **Риск:** impermanent loss выше, чем в обычном AMM, и когда цена выходит из
  диапазона, позиция перестаёт зарабатывать, поэтому её надо **переставлять**
  (задание 13).

## Что сделано в devnet

Скрипт [`scripts/11-create-pool.ts`](../scripts/11-create-pool.ts):

1. создаёт два тестовых SPL-токена (6 decimals) и минтит их на кошелёк;
2. создаёт CLMM-пул Raydium (devnet-программа
   `DRayAUgENGQBKVaX8owNhgzkEDyoHTGVEGHVJT1E9pfH`, amm config с tick spacing 60,
   комиссия 0.25%) с начальной ценой 1 A = 1 B;
3. добавляет стартовую ликвидность в диапазоне ±20% (тики `[-1860, 1860]`).

Адреса и транзакции сохраняются в [`deployments/devnet.json`](../deployments/devnet.json).

```bash
ANCHOR_WALLET=/path/to/devnet-wallet.json yarn task11
```
